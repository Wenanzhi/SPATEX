The idea

Reproduce SPATEX ↗

SPATEX uses microphone coordinates and a target direction to extract speech across different arrays. Geometry-aware channel exchange and shared temporal attention connect microphone streams, while IPD and coherence losses preserve their spatial relationships. The same model reconstructs a separate target image for every microphone.

About these examples

All three examples use the released variable-array epoch-85 checkpoint, trained with 2–8 microphones. Fixed and matched examples use linear and planar layouts; the unmatched example uses a random layout with 1 cm microphone-position perturbations. Speech comes from LibriSpeech test-clean with simulated room responses.

Examples are the first saved scenes matching each geometry and microphone count, without selection by output score. Playback uses one common attenuation gain per scene. Waveforms and spectrograms share scales across signals and microphones. Downloads retain the original floating-point multichannel output.

Metrics in the expanded rows describe individual six-second examples, rather than the paper’s two-second benchmark averages. Generation details · Sample provenance
